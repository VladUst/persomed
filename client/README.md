# PersoMed — клиент

Клиентская часть PersoMed — интерфейс персонализированной медицинской информационной системы. Приложение построено на React 19, TypeScript и Vite. Страница генетического профиля подключена к [FastAPI-серверу](../server/README.md); остальные страницы преимущественно используют демонстрационные данные.

## Быстрый старт

Требуется Node.js 18 или новее и npm. Из корня репозитория выполните:

```bash
cd client
npm ci
npm run dev
```

Адрес Vite по умолчанию — <http://localhost:5173>. Если порт занят, используйте адрес, который Vite выведет в терминале. `npm ci` устанавливает версии из `package-lock.json`.

## Доступные команды

Все команды запускаются из `client/`.

| Команда | Назначение |
| --- | --- |
| `npm run dev` | Запуск сервера разработки Vite. |
| `npm run build` | Проверка TypeScript и сборка в `dist/`. |
| `npm run preview` | Локальный просмотр собранного приложения. |
| `npm run lint` | Проверка `.ts` и `.tsx` через ESLint. |
| `npm run lint:fix` | Исправление части замечаний ESLint. |
| `npm run lint:scss` | Проверка SCSS через Stylelint **с автоматическим исправлением**; проверьте изменения после запуска. |

Автоматизированный тестовый раннер и команда `npm test` пока не настроены. Перед отправкой изменений запустите сборку и линтер, затем проверьте затронутые страницы в браузере.

## Страницы и структура

Маршруты объявлены в `src/shared/const/router.ts` и подключены в `src/app/providers/router/config/routeConfig.tsx`:

| Путь | Раздел |
| --- | --- |
| `/profile` | Цифровой профиль и медицинские документы. |
| `/indicators` | Показатели здоровья и форма показателя. |
| `/status` | Панель состояния пациента. |
| `/genes` | Генетический профиль, загрузка VCF и врачебный отчёт пациента № 1. |
| `/chat` | Демонстрационный чат. |
| `/document/:id` | Детали медицинского документа. |
| `/status/:id` | Детали элемента панели состояния. |

`src/main.tsx` монтирует приложение. Код организован по слоям FSD: `app/` содержит инициализацию, маршрутизацию и общие стили; `pages/` — страницы; `widgets/` — существующие составные блоки; `features/` — пользовательские действия; `entities/` — отображение предметных сущностей; `shared/` — переиспользуемые компоненты, утилиты и ресурсы. Внутри модулей используются `ui/`, `model/` и публичные экспорты через `index.ts`. Алиас `@/` указывает на `src/`.

## Интеграция с API

Страница `/genes` использует `openapi-fetch` и TanStack Query для трёх маршрутов `/api/patients/1/genes`: получение файла, загрузка VCF и получение отчёта. Схема типов в `src/shared/api/schema.ts` сгенерирована из OpenAPI текущего сервера. FastAPI публикует документацию по адресу <http://localhost:8000/docs> и схему по адресу <http://localhost:8000/openapi.json>, когда сервер запущен.

По умолчанию API доступен по адресу `http://localhost:8000`. Другой адрес задаётся через `VITE_API_BASE_URL` в `.env.local`. Сервер разрешает запросы с `http://localhost:5173` и `http://127.0.0.1:5173`; если Vite выбрал другой порт, задайте его в `PERSOMED_CORS_ORIGINS` на сервере. Схему можно обновить командой `npx openapi-typescript http://localhost:8000/openapi.json -o src/shared/api/schema.ts` при запущенном сервере.

VCF и отчёт содержат чувствительные медицинские данные. Интерфейс показывает ограничения анализа, статус частичных источников, качество входных данных и технический JSON; интерпретация требует клинического подтверждения.
